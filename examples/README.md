# Examples

These files are sanitized references only. They are not loaded by deemon or deemix.

- `deemix/config.json`: a sample Deemix settings file. Copy it to Deemix's own configuration directory and set `downloadLocation` for your system.
- `deemix/spotify-config.json`: a blank legacy Deemix Spotify-plugin settings example.

Keep ARL tokens, Spotify credentials, and personal output paths in user-local configuration, never in this repository.
